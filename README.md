# YouTube Home Page Clone

This project is a static clone of the YouTube home page, created using only HTML and CSS. It's a great example of how to build a complex and responsive layout with modern CSS techniques like Flexbox and Grid.

## Description

This project faithfully recreates the look and feel of the YouTube home page. It includes the header with the search bar and user icons, the collapsible sidebar with navigation links, and the main content area with a grid of video thumbnails. The project is built to be responsive, ensuring a good user experience on different screen sizes.

## Features

- **Responsive Header:** The header contains the YouTube logo, a functional search bar, and user-related icons. It adapts to different screen sizes.
- **Collapsible Sidebar:** A vertical navigation bar on the left with icons for Home, Explore, Subscriptions, and more.
- **Video Grid:** A responsive grid of video thumbnails, each with a title, channel name, and view count.
- **Tooltips:** Hovering over icons reveals tooltips, just like on the real YouTube site.
- **Static Video Data:** The video information is hardcoded in the HTML, providing a realistic representation of the YouTube layout.

## Technologies Used

- **HTML5:** For the structure and content of the web page.
- **CSS3:** For styling the page, including:
    - **Flexbox:** For creating flexible and responsive layouts in the header and other components.
    - **CSS Grid:** For creating the main video grid layout.
    - **Responsive Design:** Using media queries to ensure the layout adapts to different screen sizes.

## File Structure

```
YouTube Home Page With HTML & CSS/
├── general.css
├── header.css
├── sidebar.css
├── youtube.html
├── icons/
│   ├── channel-picture.png
│   ├── explore.svg
│   ├── hamburger-menu.svg

│   ├── library.svg
```

- **`youtube.html`:** The main HTML file that contains the structure of the page.
- **`general.css`:** Contains the general styles for the body, typography, and other global elements.
- **`header.css`:** Contains the styles for the header section, including the search bar and icons.
- **`sidebar.css`:** Contains the styles for the collapsible sidebar.
- **`icons/`:** A directory containing all the SVG and PNG icons used in the project.
- **`video-image/`:** A directory containing the video thumbnails and channel profile pictures.

## Setup and Usage

To view the project, simply open the `youtube.html` file in your web browser.

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/YouTube-Home-Page-With-HTML-CSS.git
   ```
2. Navigate to the project directory:
   ```bash
   cd YouTube-Home-Page-With-HTML-CSS/YouTube Home Page With HTML & CSS
   ```
3. Open `youtube.html` in your favorite web browser.
